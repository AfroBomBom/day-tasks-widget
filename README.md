# Дела на день

Виджет списка дел для рабочего стола Windows. Работает локально, без интернета и регистрации.

![Иконка](assets/daytasks.png)

## Запуск

Скачайте файл [DayTasks.exe](app/DayTasks.exe), поместите его в отдельную папку и запустите. Нажмите **Win + D**, чтобы увидеть виджет на рабочем столе.

Для автозапуска создайте ярлык программы и скопируйте его в папку, открываемую через **Win + R → `shell:startup`**.

## Возможности

- Добавление дел через Enter или кнопку +.
- Отметка выполненных дел и отмена отметки.
- Компактный список дел, который плавно расширяется при переходе на вкладку «Матрица Эйзенхауэра»: «Важно · срочно», «Важно · не срочно», «Не важно · срочно», «Не важно · не срочно». В каждом разделе матрицы есть строка ввода: Enter добавляет задачу сразу в этот раздел. Кнопок «+» и «Из списка» нет. Дела из общего списка распределяются вручную через «⋯», без копирования. Через это же меню можно изменить раздел или убрать дело из матрицы, сохранив его в списке.
- Незавершённые дела остаются на следующий день.
- Выполненные удаляются после 03:00 по времени компьютера. Если программа закрыта, очистка происходит при следующем запуске.
- Перемещение виджета за заголовок с сохранением положения.
- Восемь оформлений: «Синий · ночь», «Жидкое стекло · прозрачное», «Стекло · ледяное», «Стекло · дымчатое», «Стекло · светлое», «Светлый голубой», «Тёмный · мята», «Лавандовый».
- Стеклянные темы с размытым изображением обоев за виджетом, тонкими рамками, чётким текстом и мягкой внешней тенью. Изображение обоев обрабатывается в памяти и не сохраняется в проект.
- «Синий · ночь» — оформление по умолчанию. Выбранное оформление сохраняется.

## Личные данные

Дела, положение и оформление хранятся в папке `Данные` рядом с программой. Эта папка исключена из Git и не отправляется на GitHub. Приложение не передаёт дела в сеть.

## Сборка

Нужны Windows 10/11 и .NET Framework 4.8. Дополнительные библиотеки для приложения не требуются.

```powershell
./build.ps1
```

Готовое приложение: `app/DayTasks.exe`. Скрипт также проверяет перенос дел, сохранение списка и переключение оформлений.

Дополнительная проверка прозрачности и тени на доступном рабочем столе:

```powershell
./build.ps1 -DesktopTests
```

Основной код находится в `src/`, иконки — в `assets/`. Для повторного создания иконки нужен Python с Pillow; для обычной сборки это не требуется.
